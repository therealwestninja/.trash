# Architecture Overview

Sweet Freedom is transitioning to a **runtime-based robotics architecture**.

---

## Core Layers

1. UI Layer
2. API Layer
3. Runtime Core
4. Capability Modules
5. Hardware Interface

---

## Data Flow

User / AI / Script  
→ Command  
→ Runtime  
→ Capability  
→ Robot  

Robot  
→ Event  
→ Runtime  
→ UI

---

## Design Goals

- Modular
- Extensible
- Real-time
- Safe
- Hardware-agnostic
